# SpicyMango Portfolio

Premium Minecraft, web, and Discord developer portfolio built with React, TypeScript, and Vite.

## Run locally

```bash
npm install
npm run dev
```

## Deploy to Vercel

1. Import this repository into Vercel.
2. Keep the project root at the repository root.
3. Use the default Vite settings:
   - Build command: `npm run build`
   - Output directory: `dist`
4. Deploy.

The included `vercel.json` keeps the client-side `/plans` route working after refreshes.

## Included

- Minecraft and Discord plan catalog at `/plans`
- Currency switcher for plan pricing
- Interactive developer terminal with safe portfolio commands
- Responsive dark/light theme
- Static assets and Vercel SPA routing configuration
